# Changelog

## 0.1.0 — 2026-11-23

First working release.

- JSON scenarios for a fixed 1:1 trial with a synthetic continuous endpoint.
- Weekly accrual calendar, independent dropout by arm, and a complete-case two-sided pooled t-test.
- Monte Carlo rejection frequencies with Clopper-Pearson intervals, invalid-analysis counts, and a baseline comparison.
- Command-line validate, run, and compare commands, plus text, JSON, and HTML reports.
- Authored fixtures only. No remote data and no patient records.
